# Fonts

**Source Sans 3** (Paul D. Hunt, Adobe), variable weight 400 to 700, self-hosted here as two woff2
subsets (latin, latin-ext) so the site never calls a font CDN. Licensed under the SIL Open Font
License 1.1: https://github.com/adobe-fonts/source-sans/blob/release/LICENSE.md

The files were taken from the Google Fonts build on 28 Sep 2026. To refresh them, request
`https://fonts.googleapis.com/css2?family=Source+Sans+3:wght@400..700` with a modern browser
user agent and download the `latin` and `latin-ext` woff2 URLs it lists.
